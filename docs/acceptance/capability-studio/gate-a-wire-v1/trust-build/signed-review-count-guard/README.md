# Signed review-count guard fixture

This directory is generated by `../generate-signed-review-count-guard.mjs`.
It uses a fixed, fixture-only Ed25519 seed. The key is not an operational
credential and must never appear in a production trust policy.

All four wire documents pass their structural Schema. The Review Body contains
one open P0 finding while the Review Body and signed Envelope both report
`openP0=0`. The Ed25519 signature is valid. A2 must therefore return:

```text
FAIL / REVIEW_COUNT_CONSISTENCY_REJECTED / exit 2
```

This proves that signature validation is necessary but insufficient: A2 must
derive review counts from `reviewChecks` and `findings` after verifying the
signature, then compare every projection.
